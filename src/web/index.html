    Ausgehende Ziele

    Match-Daten an eine IP:Port im lokalen Netz schicken — als HTTP-Webhook, als offene TCP-Verbindung oder als UDP-Pakete. Jedes Ziel sendet dieselben JSON-Nachrichten wie der Live-Stream ({"type":"event"|"state", …}).
